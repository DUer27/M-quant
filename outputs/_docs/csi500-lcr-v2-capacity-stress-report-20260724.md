# 中证500低拥挤反转指数增强候选策略 v2 最大资金承受压力测试报告

生成时间：2026-07-24 13:37 中国时间  
测试对象：中证500低拥挤反转指数增强候选策略 v2  
测试区间：2025-01-01 至 2026-07-22  
主测试口径：每日选分数最高的前 10 只、动态持仓、15 只候选名单、本地真实行情及补齐缓存行情  

## 一、核心结论

当前 v2 在收益率回放上，即使提高资金规模，仍然会显示较高收益率。但这不代表策略真实可承受高资金，因为现有资金账本只处理手数取整、固定佣金、固定滑点、印花税和现金缓冲，没有把大资金带来的成交冲击、排队成交失败和价格滑移非线性写入收益率。

因此，本次“最大资金承受”不以高金额回测收益率为准，而以逐笔买卖占当天真实成交额的参与率为准。

按主口径“每日选前 10 只”：

- 保守可执行资金上限：3000 万以内。
- 5% 成交参与率理论边界：3144 万，但实际阶梯回放在 3144 万时最大参与率已到 5.14%，因此不建议把 3144 万作为执行上限。
- 激进观察区间：3000 万至 5000 万。
- 超过 6000 万后进入 10% 参与率压力区。
- 1 亿以上不应相信当前收益率，应视为高冲击压力情景。

可以看到，收益率随资金提高没有明显下降，核心原因是当前账本还没有引入成交冲击成本。因此容量判断必须看参与率，而不是只看收益率。

这里平均持仓天数在不同资金规模下几乎相同，是因为当前资金阶梯只放大成交股数和成交金额，不改变选股信号、买入日期和卖出规则。只要资金大到每笔都能按手数买入，持仓开始和退出日期就不会因为资金变大而改变。真正会让平均持仓天数变化的，是加入单日成交上限、部分成交、延迟成交、成交失败或冲击成本后的“真实容量模型”。

## 八、最终建议

当前 v2 的实操资金建议如下：

| 资金范围 | 建议 |
|---:|---|
| 1000 万以内 | 相对舒适，可作为观察运行区间 |
| 1000 万至 3000 万 | 主推荐执行区间 |
| 3000 万至 5000 万 | 激进观察区间，需要盯成交参与率和盘口滑点 |
| 5000 万至 6000 万 | 接近 10% 压力区，不建议常态运行 |
| 6000 万以上 | 高冲击压力情景，当前收益率不可信 |
| 1 亿以上 | 必须加入冲击成本、成交失败和分批执行模型后再判断 |

最终结论：

**以 5% 单票成交参与率为保守红线，v2 当前最大资金承受建议为 3000 万以内。**

## 九、后续必须补充的测试

1. 加入非线性冲击成本：参与率超过 3%、5%、10% 时追加滑点。
2. 加入成交上限：单票单日最多成交当日成交额的 5% 或 10%，超出部分保留现金或延迟成交。
3. 加入分批执行：把单日买卖拆成多日成交，观察信号衰减后收益是否仍成立。
4. 用 JoinQuant 原生账本复核停牌、涨跌停、指数成分、真实成交额和权重约束。
5. 对“每日选前 10 只”与“每日选前 15 只”做同口径超额、跟踪误差和换手对比，判断扩容是否值得牺牲收益质量。
