# AkShare 指数增强研究报告

生成时间：2026-07-14

## 结论

当前最值得继续推进的指数增强方向是 `f_volume_confirmation`，即量价确认 Alpha。

早期多因子复合版本虽然覆盖了动量、低波、回撤、反拥挤、残差风险等因子，但在沪深300和中证500上并没有稳定跑赢等权基准。单因子组合诊断后发现，真正有效的信号集中在 `f_volume_confirmation`：20日收益经过截尾后，与 20/60 日均量变化方向相乘。它捕捉的是“价格方向和量能方向一致”的横截面优势。

## 数据边界

- 使用真实 AkShare OHLCV 日线数据，前复权 `qfq`。
- 当前使用静态指数成分池，不使用历史成分变化。
- 当前基准为成分股等权收益，不是真实指数收益或真实指数权重收益。
- 腾讯日线源缺成交额和换手率；本研究不伪造成交额、换手率、市值、行业或基本面。
- 当前回测未处理停牌、涨跌停不可成交、真实滑点、冲击成本和容量约束。
