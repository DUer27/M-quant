## 使用边界

- 这不是全市场回测，不能直接升级为模拟盘策略。
- 分层强结果只有 33-39 次样本交易，必须扩时间、做样本外验证。
- 腾讯源只提供真实价格/成交量，不提供东方财富成交额/换手率；本地流动性层为成交额优先、缺失时用真实成交量兜底。
- 这批结果可以说明：在沪深300本地 300 股、2024-2026 样本中，分层比未分层更关键。
- 低波动确认路线、高波动回归路线值得迁移 JoinQuant 复核。
- 当前两条准模拟盘候选仍以 JoinQuant 真实结果为主：`JQ质量利润流动性策略 v1` 与 `K线辅助确认策略`。
