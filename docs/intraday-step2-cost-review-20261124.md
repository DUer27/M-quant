# 第二步代价评估与隔离自检

日期：2026-11-24，北京时间。仅评估方案并运行隔离容量/故障检查，没有修改采集程序、调度开关或正式行情数据。

## 当前实测与模型

- 试验目录383个文件、约30.08MiB；状态文件约4,261.6KiB，分钟缓存约3.05MiB。
- 实际状态HTTP响应约1.986MiB，一次本机读取约0.084秒。可见页面每5秒请求一次，按连续打开4小时估算约5.59GiB本机传输；这不是互联网流量，也不是长期新增磁盘量，但会产生解析、对象分配和重复绘图成本。不同页面、压缩和后续数据变化会改变结果。
- 每轮两次报价批量请求＋50次分钟请求，健康情况约52次；最近一轮含一次失败主源为53次。按240轮模型为12,480—12,720次/交易日，不包括额外补采。不是供应商批准的额度。
- 50只×240分钟用于容量模型为12,000条独立分钟记录；若每分钟取完整当日序列，理论累计传输记录量约1,446,000条/日，约120.5倍。真实接口含集合竞价、缺失分钟等，不能用该模型填补行情。
- 按当前两路报价JSON平均约766字节/条估算，50只、两来源、每分钟存一份、240轮约17.53MiB/日，仅报价载荷。提到每秒记录相同结构时，量级可能约60倍；不含数据库索引、原始响应、备份等。
- 当前C盘空余约137.6GiB，E盘约83.4GiB，短期空间并不紧张；没有自动清理或删除历史。

## 代价与降低办法

| 代价 | 降低办法与仍存在的边界 |
| --- | --- |
| 高频请求及补采放大限流 | 共享来源请求预算，优先最新报价和最新分钟，补采只用剩余额度；失败退避并遵守Retry-After。分进程不意味着有独立额度，不能靠更多并发消除限流。 |
| 全量状态传输与绘图 | 轻量监控接口与分钟序列分离；按所选股票加载、按版本/变化更新；非可见图暂停绘制。暂不需要引入消息中间件。 |
| 快照、原始记录、修订和备份增大存储 | 区分可重建缓存和需追溯记录；分钟主键去重、增量写入、批量事务；原始响应设置可配置保留期，先归档再考虑删除。保留期意味着可追溯范围的取舍。 |
| 数据库锁和故障 | 单写入队列、短事务，读写分离连接；队列有界，数据库忙时显示积压，不阻塞报价展示。维护checkpoint、磁盘阈值与恢复备份；不能把同盘复制当独立备份。 |
| 长驻进程与历史队列增加复杂度 | 先保持一个采集服务，分最新报价/分钟/补采队列；同来源统一限速；补采拆小片段、限制并发、设超时和每日预算，重启后可恢复。最新行情优先时历史补齐可能更慢，需显示预计积压而非隐藏。 |
| 闭合确认增加等待 | 正式策略只用来源语义已验证且通过校验的闭合分钟；页面独立显示形成中/待验证数据。允许降低时效以换取正确性，不能因墙上时间已过一分钟就标闭合。 |
| 去重、修订与切源误判 | 保存来源和收到时间；同周期冲突保留版本，按明确口径选择；观察原始数据并列核查。双源核对增加请求，先小样本抽查，不每轮全字段双倍重抓。 |
| 运行维护、开机和睡眠影响 | 心跳、断线状态和启动恢复检查；先不增加云服务。关机时无法持续采集，恢复后补查也不等于当时实时在线。未来托管或更可靠来源可能增加持续费用，需接入前核实权限与预算。 |

## 隔离自检（7项通过）

用临时SQLite数据库、明确标记为synthetic-test-only的数据，未写入正式行情目录：

1. 写入12,000条模拟分钟记录，约0.0259秒。
2. 重复及反序重放后仍为12,000条。
3. 100条价格修订保留对应修订记录。
4. 写事务未提交时，独立读连接仍读到已提交的数据。
5. 第二个写连接被阻塞，证实单写入队列的必要性。
6. 未提交写连接关闭后，重新打开没有残留未提交记录。
7. 数据库完整性检查返回ok。

checkpoint后数据库约1.855MiB，只包含简化分钟表、主键和100条修订，不包含完整报价、原始响应、完整审计字段和备份。此结果不作为生产体积承诺；连接关闭回滚也不是断电或硬盘损坏恢复测试。

自检产物：`outputs/live-market-data/intraday-trial/qa/cost-selfcheck.json`。没有重复跑行情采集，也没有实施自动清理。

## 修订后的分批顺序

第一批调整为“轻量监控接口＋独立数据库基础”，先解决已经看到的大响应成本；与现有缓存短期并行核对，先稳定同一轮数据的一致性，再切读源。之后才做闭合语义、小样本冲突/缺口处理、常驻服务与补采队列、真实盘中持续验收。首次数据库改造不立即引入全量原始数据永久保存、分布式服务或自行聚合盘口K线。

尚未自检的生产边界：数据源持续可用性和授权额度、真实分钟闭合语义、补采队列在高负载下的资源隔离、真实断电与备份恢复。后续每批单独验收，不用本次存储自检代替这些测试。
