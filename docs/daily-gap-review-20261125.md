# 历史日线缺口交叉核查

2026-11-25，北京时间。已部署本地平台，未提交或推送；未启动或重置连续验收。

## 使用

数据采集中心 → 股票数据管理库 → “历史日线缺口交叉核查”。点击“核查历史缺口”，检查已经保存并完成历史准备的日线股票；未保存草稿不能执行。面板逐股显示缺失日期、主历史来源、交叉核查范围、来源是否成功、找到/仍缺的日期数量、重叠日期价格差异及具体日期。

本批自动列出实际缺口，网络交叉核查由按钮触发，避免对已知缺口反复请求。每批最多3只，只尝试主历史之外的来源，每个来源最多1次；当天最多12次提供方尝试，先预占额度，进程中断也不退回。相同基线已核查的记录复用；部分来源未成功时，30分钟后可再次点击。缓存或校验要求变化会把旧证据标为待复查，历史未准备者先执行历史准备。

仅在已确认休市时执行，交易日09:25—15:05含午休保留给最新行情。与日线更新、历史准备共用写锁，控制器阻止重叠历史任务，检测到最新任务或运行超过4分钟会结束其创建的进程树。平台服务必须运行。

## 证据与边界

使用缺口前后已存在记录作为范围边界，交叉来源必须覆盖两端并通过日期、代码、OHLC和前复权检查，才记录“观察到缺失”。请求失败、冷却、范围不全分别保留，不计作缺失证据。

其他来源找到缺失日期时，只保存完整的交叉窗口和候选文件，不拼接主历史。重叠OHLC按相对0.01%、绝对0.02的容差检查差异，仅作为核查线索；不同来源或复权基准可能不同，差异不直接证明某方错误。候选零成交量会单独标记，不作为可直接使用的有效成交证据。

多个来源均缺失仍不能单独确认停牌，必须补充相应公告或其他明确证据。本批不生成停牌结论，不补零，不修改任何主行情CSV、正式日线快照、观察信号或分钟数据。
