## 页面

数据采集中心 → 质量与记录 → “分钟K线状态与策略准入”。

全池表逐股显示分钟样本数量、接收时可能形成中、边界标签待核实、闭合待验证、隔离未来候选、内部疑似缺口及紧邻边界待核查的标签数，并单独显示本轮/缓存/历史日期/休市等时间状态。

下方3只核查样本为管理库当前配置的600519、000001、000063。可切换查看最近30根标签的状态、同源观测次数、连续未变次数、修订次数、是否见到后续标签；证据不足时显示“未记录”，不会补造次数。图表页仍可观察分钟走势，同时明确提示当前策略不可用。

只有质量页可见时才获取所选样本的逐根详情；其他页面不增加详情请求，同版本及相同接收时刻复用详情，并合并同时发起的重复读取。切换样本、采集版本变化或响应失败均不能把旧详情当成当前准入。

## 使用规则

- 形成中状态按原接收时刻判断，页面等待到下一分钟不会自动把它变成已闭合。原始未来候选独立计数，不参与普通标签之间的缺口计算。
- 09:30、11:30、13:00、15:00标签单列为边界待核实。相邻已见标签之间若跨越午休，不生成午休缺口；紧贴时段边界的间隔另列为边界待核查，不直接判为漏数。
- 稳定性证据只比较同股、同源、同口径、同标签。不同运行且接收时间确实推进才增加独立观测次数；内容修订重置连续未变次数。换来源/口径重新建立证据，不跨来源混算。每股只保留当前最多300根标签证据。
- 同源重复不变、出现后续标签或经过较长时间，都只是观测线索，不是来源标签含义或正式闭合的证明。当前新浪、东财分钟适配器的标签与闭合规则仍标为unverified，本批不提供配置开关绕过验证。
- 代码/时间/OHLC/数量/来源或口径异常、序列重复、混入多日、缓存版本不匹配、旧缓存等会记录阻断原因。观察图表与策略取数入口分离。

## 接口与执行边界

- GET /market-data-api/intraday/minute-readiness：全池摘要，附加到原status和summary响应；不返回全池逐根标签。
- GET /market-data-api/intraday/minute-readiness?code=600519：该股最近30根状态和最多10段缺口详情。只接受当前分钟池代码，移出/未启用分钟的代码返回400。
- GET /market-data-api/intraday/strategy-minutes?code=600519：新的策略分钟输入入口。当前来源规则未验证，返回409、available=false、blocking_codes和空bars列表。即使观察缓存写有closure_verified=true或已重复100次，也不会绕过此入口的规则。

本批建立的是新的策略分钟输入入口；尚未将全部现有研究/日线策略重接到该入口，也没有把观察分钟开放给现有策略。没有新增正式已闭合K线，没有自动下单逻辑。
