# 模型解释板块预览

日期：2026-11-25。本文记录本轮模型解释板块的实现与验证。版本保存状态以 Git 提交及版本标签为准；`cc` 仓库的 `v1.1` 基线保持不变。

## 体验路径

打开本地平台后，点击侧栏“模型解释”。也可以从以下位置进入对应章节：

- 研究流水线 → 选中因子 → 因子档案中的“查看模型解释”。
- 复测中心 → “信号到收益”标题旁的解释入口。
- 策略池 → 组合构建标题旁的解释入口。
- 实测结果 → 收益分解标题旁的解释入口。

解释目录分为因子构造、收益映射、组合权重、收益分解和统计判断。默认先读白话说明，公式按需展开，保持“公式在上、字母含义在下”。

## 界面与计算的边界

- 原因子档案先展示研究证据，不再默认进入数学公式标签。
- 回测配置保留原来的参数编辑、保存与估计操作。
- 解释页为只读；“解释口径”只切换展示当前配置或已估计模型快照，不修改参数。
- 当前配置含未保存修改时，不借用旧模型系数；选择历史快照时，按该快照实际保存的参数解释，并标明不可继续应用的状态。
- 未绑定的原登记因子不会继承其他本地算子的系数；全局模型章节的标题不冒用当前选中因子的名称。
- 从上下文入口进入后，“返回研究页面”保留原页面、滚动位置和未保存表单，恢复入口焦点。
- 本轮没有改动 Python 统计引擎、收益映射服务、优化算法或实际模型参数。

## 工程实现

沿用原生 JavaScript ES modules、现有 CSS 色板及原生 MathML。解释渲染拆为独立的 `return-mapping-explanation.js`，复用原有数学函数和 API 数据，没有新增前端框架或运行依赖。

新增模块载入错误提示；模块不可用时不无限显示加载占位。浏览器检查同时暴露并修复原有研究智能体的 `dateOnly` 未定义错误。

封存前复核还发现首页同时标记两个活动视图，首次从研究智能体进入解释后可能返回总览。现已统一首次活动页面及研究导航分组，并增加首次进入、分组默认页和解释返回的回归测试。
