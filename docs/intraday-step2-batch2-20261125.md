## 页面与功能

刷新 http://127.0.0.1:5555 ，在盘中数据区域、独立存储提示下方查看“分钟标签与缺口核查”。展开后可看000001、000002、000063的来源、标签范围、同源观测次数、修订、内部疑似缺口、乱序与时间倒退，以及开盘、午休和收盘边界标签。50只采集保持原配置，先核查其中3只。

- 核查复用已经返回的分钟序列，不新增日常行情请求。对原始标签乱序进行排序并留下标识；重复标签仍整段拒收，由原有备用来源或成功缓存兜底，不擅自选择冲突行。
- 同一来源、股票、复权口径和日期才比较修订，报告变化字段及旧值/新值示例；来源切换单独提示，切回可与该来源自身的上次成功基线比较。旧接收记录和标签倒退不会覆盖较新核查基线。
- 缺口只统计同一已观察时段内两个标签之间的候选缺失标签。午休不计缺口；开收盘口径、完全缺失的时段及停牌状态仍未知。不会补零，也没有启动自动补采。
- 与接收时间处于同一分钟的标签仅提示“可能形成中”。所有标签闭合语义仍为unverified，正式闭合数量保持0，策略可用标志保持false。墙上时间经过、重复返回不变或字段检查通过都不会自动确认闭合。
- 旧日、旧轮或与当前显示序列版本不一致的核查结果标为历史结果，不计为本轮核查。
