# 图表表达与布局优化

2026-11-26。本批优化本地数据采集中心的“行情图表”页；不改变50只股票池、报价/分钟调度、来源权限或策略准入，也没有启动新的统一持续验收。刷新网页即可读取新前端资源，无需重启采集服务。改动尚未提交或推送。

## 页面变化

- 顶部四项概览：同日报价覆盖、上涨/下跌与平盘/未知、中位涨跌幅、样本累计成交额。明确当前来源、来源日期及时间范围，报价时间显示到秒。
- 新增股票池涨跌占比与七档分布，以及累计成交额Top 6。成交额条目可直接切换股票。仅统计当前股票池，不称为全市场；不把两个报价来源的同一股票重复相加，不跨日期汇总。
- 原50只涨跌排行改为最高434px的独立滚动区；窄屏最高300px，加入名称/代码筛选。筛选只影响排行及状态列表，概览仍统计完整股票池。自动刷新保留滚动位置。
- 所选股票补充开盘/昨收、高低价与振幅、累计量额及买卖一价差。价格图增加昨收参考线与“已获取分钟样本累计均价”；报价与分钟日期不同则隐藏昨收线。
- 下方柱状图可切换分钟成交量或分钟成交额。悬停数值包含开高低收、量与额；来源未提供成交额时明确显示缺失，不用成交量代替。
- 50张逐股状态卡改为默认折叠、内部限高330px；前面保留报价覆盖、盘中及时报价及分钟获取摘要，避免状态卡占满页面。窄屏改为分列或单列。
- 采集耗时分为报价与分钟两个小图，各展示最近20条，分别标出目标、中位数与P95。中断和无效时长以叉号单列，失败或真实超时记录仍保留在耗时统计中。

## 口径与防误读

`intraday-chart-data.js`集中计算来源隔离、股票池去重、北京时间日期、涨跌分布、样本均价及耗时分布。无有效昨收或价格为0时，涨跌为未知，不当作平盘；无成交额为缺失，真实0成交额仍保留为0。

样本均价使用已取得分钟的累计成交额÷成交量，而非收盘价简单平均。它不是全日均价或闭合承诺；分钟量额不完整时不绘制该线。价格线与均价线都在缺口、午休处断开，不补零、不连造行情。现有分钟闭合限制及策略不可用提示继续显示。

联调发现最近分钟历史包含“上次独立任务中断”记录，elapsed_seconds为27482.057。这是停止运行后恢复时形成的中断间隔，不能解读为一次行情下载耗时约7小时。本批仅在图表统计中将此类记录单列；原历史、错误及原始时长没有修改，仍可在质量与记录中追溯。真实180秒超时等失败记录不会因为失败就被排除。
