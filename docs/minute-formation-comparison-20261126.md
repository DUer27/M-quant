# 分钟形成过程对照：第一批

2026-11-26，北京时间。当前50只报价/分钟股票池及自动开关保持不变，本批复用已有三只核查样本的归档，不追加外部行情请求，不启动或重置统一持续验收。本地改动未提交或推送。

## 在哪里查看

刷新本地平台，进入“数据采集中心 → 质量与记录 → 分钟K线状态与策略准入 → 来源核实与边界观测”。每只核查样本新增“同一分钟跨轮对照”：

- 按来源和不复权口径分别统计独立观测、最新标签推进/停滞/倒退，以及重叠标签发生的修订。
- 展开最近8个标签，查看首次/最近归档接收时间、最近开高低收、成交量/成交额、观测次数、修订次数及是否见到后续标签。
- 显示最多3条最近修订的前后数值，并单列“此前已出现后续标签仍发生修订”。此类记录有助于发现不能仅凭下一根出现就认定闭合的问题。
- 边界标签的“响应中留存”与“标签后180秒内接收”分别计数。午后响应内含11:30旧标签，不能算作午间边界附近的形成观测；180秒仅为本项目的观察分类条件，不是供应商闭合规则。
- 页面自动刷新保留已展开的对照表；本功能没有新增前端轮询或行情请求。

## 实现与边界

`tools/intraday_formation.py`为无网络、无写库的归档比较器，由原边界归档导出路径调用。仅使用origin=live且满足原盘中证据条件的记录；历史导入、其他日期、无效时间和字段不计入。同源同口径同运行编号只取最终接收记录，等价时区与相同接收时刻不虚增独立轮数。来源之间不比较价格修订。

比较范围仍受现有单份最多32个重点标签、每股每来源每日600份上限约束。导出只附带每来源最近8个标签及3条修订，未将全部档案塞入页面。三个样本当日重新导出实测0.0687秒，属于一次本机实测，不能代表扩池后耗时保证。

首次归档见到某标签，不是该分钟开始形成的时刻。60秒采样及有限尾部归档无法还原一分钟内完整价格路径；未观察到修订也不证明最终闭合。来源标签含义、闭合规则及策略门槛本批均未放宽。
