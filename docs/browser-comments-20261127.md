## 2. K线缩放与平移

K线上方新增：放大、缩小、前移、后移、回到最新、重置。价格与成交量/额共用同一视窗；Ctrl＋滚轮在图内缩放并锚定附近真实标签，普通滚轮仍用于页面滚动。
