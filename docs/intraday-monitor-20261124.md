# 自动采集监控面板

已在盘中50只股票区域、图表上方增加独立“自动采集监控”，入口 http://127.0.0.1:5555/#automatic-collection-monitor 。

直接展示：真实运行状态（自动/手动采集、暂停、休市等待、异常、连接中断）、自动开关、当前间隔、下一次北京时间与每秒倒计时、今日自动盘中完成轮数、最近完成结果与触发方式、报价/盘口及分钟覆盖进度、最近8条明确自动触发的时间线。

暂停/启用和手动采集按钮集中在监控头部。页面每5秒取后台状态，每秒仅刷新倒计时，不触发行情请求。后台每秒检查调度，接口返回实际last_tick_at；超过15秒心跳未推进会显示调度响应延迟。网页失联保留上次结果，明确显示连接中断，不继续伪装为运行正常。

下一交易时段根据现有交易日历推算，午休跳到13:00，夜间跳到下一交易日09:30；日历不足时不猜日期。估计时间依赖电脑与平台服务持续运行。进度只表示本轮接口覆盖，不保证源时间新鲜。旧记录没有明确自动标签时不计入自动时间线，手动采集不能作为自动执行证据。

自检：50项Node测试全部通过，包含下一交易日/午休/周末、倒计时、自动手动区分、暂停/失联/异常、心跳停滞、覆盖进度、上一完成结果保留及空自动时间线。采集Python代码本轮未改。

实际服务：自动开关true、休市等待、今日自动盘中0轮；下一交易时段为2026-11-25 09:30北京时间。HTTP核对面板和模块可访问，以实际状态调用渲染函数得到相同文案；两次读取确认后台心跳推进。服务已重启，错误日志为空。当前浏览器连接工具不可用，未进行整页浏览器截图验收。
