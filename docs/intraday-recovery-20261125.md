# 盘中分钟采集修复与逐级实测

日期：2026-11-25，北京时间。已部署本地采集程序、控制器和页面；自动采集仍保持原先的暂停状态。代码未提交或推送。

## 本次修复

1. 新浪下一分钟边界候选单独隔离：只有交易时段内、恰好位于下一分钟边界、原响应最后一行的单条记录可进入pending_rows。其OHLC、数量、时间范围和重复检查照常执行。其他未来时间、重复标签、异常价格或仅有候选而无可用历史标签的序列仍拒收。此规则只对已观察到该行为的新浪分钟解析启用，东财不套用。
2. rows只含已到源标签时间的待验证样本；source_time、数量、时效、图表版本和分钟候选数据库均基于rows。pending_rows保存于成功缓存/手动运行报告，轻量摘要只带候选数量和标签，不带其数值数组。候选不计入样本覆盖，也不写入正式闭合K线。
3. 网络失败、限流/访问限制、内容校验、本地写入异常分别标记。单股内容问题不再触发整个来源的5分钟冷却；真实连接连续失败及403/429继续按来源退避，遵守Retry-After。来源冷却到期允许探测；再次连接失败重新冷却，成功后恢复正常请求。
4. 当前配置将新浪排在东财之前。健康主来源成功时不额外请求备用源；备用源只在需要时请求，连接失败仍受预算和冷却约束。没有修改系统代理，也没有宣称修好了东财连接。
5. 采集监控新增每个分钟来源的请求、网络返回、有效样本、跳过和隔离候选数量，以及失败类型和冷却时间。未使用的来源明确显示“本轮未请求该来源”。报价成功但分钟不完整时显示单独的提示。

这些“分钟样本”仍全部closure_verified=false。源标签到时不意味着周期闭合，正式策略资格仍未开启。
