# 日内K线与精简周月视图

2026-11-27，北京时间。已部署本地平台，刷新“数据采集中心 → 行情图表”即可使用。行情图区域默认展示K线，仍可切回原分时线；复用原价格与量额区域，没有额外堆叠大图。未提交或推送。

## 使用方式

- 走势：K线 / 分时线。
- 周期：日内1分钟 / 最近12根周K / 最近12根月K。
- 日内范围：当天全部 / 最近60根 / 最近30根；保留每根原有分钟OHLC，不合并为更粗粒度。周月视图禁用日内范围选择。
- 成交指标：成交量或成交额，单位随周期显示。周月成交量由日线缓存的手换算为股，与分钟图保持一致。
- 悬停、点击或键盘聚焦K线可查看日期、开高低收、成交量与额。详情默认跟随最新K线，用户选择历史位置后在后续刷新中保留该位置。

红色表示收高于开，绿色表示收低于开，平盘灰色。影线覆盖高低价。日内横轴保留午间空白和实际时间间隔，异常/缺失不补零；同一时刻出现冲突OHLC时停止绘图，不任取一个版本。

## 数据口径

日内只使用所选股票已保存的来源分钟OHLC和量额，不根据每分钟抓到的报价合成K线，不把隔离的未来候选绘入。图上明确来源、日期、已有和显示条数、源标签截止时间及采集暂停/缓存状态；历史日期不会冒充今天。所谓“精确”在本批指逐根保留已有来源数值，不表示已证明交易所逐笔完整性或分钟闭合。

周K按北京时间自然周周一至周日分组，月K按自然月分组；取首个日线开、最高价、最低价和最后日线收，量额求和。只聚合同一来源、同一复权口径的已保存日线；不将报价或分钟数据拼入未完成日线。当前缓存是前复权，页面会标明，与日内不复权数据切换时避免混淆。

周月最多返回12根，但横轴仍按真实周/月间隔定位：整期没有数据会留空，不挤成连续走势。交易日历用于列示疑似缺失、待到期天数与日历外标签，未知日历不宣称完整；虚线实体表示日线覆盖未齐或日历待核实。缺失并不直接解释为停牌或来源故障。

沿用既有16:30日线截止边界：16:30前不把当天日线纳入聚合。2026-11-27本次检查中，周月日线截至11月26日，当前周/月尚未收齐；并未用11月27日的分钟数据伪补当天日K。

## 获取与资源

新增只读接口`GET /market-data-api/intraday/candles?code=600519&period=week&pool_version=2`，period可为week/month。仅接受当前报价池代码并检查管理库版本；参数不合法400，旧版本409。直接读取本地CSV，最多4MB/10000行，并检查日期、重复、OHLC、股票代码、来源与复权一致性。

周/月仅请求当前股票的精简数据，前端在同一股票/周期/池版本下60秒内复用、合并并发请求、失败保留旧结果并标明。切换到周月不额外下载分钟序列，来源不可提供成交额时显示缺失，不用成交量或0代替。没有新增外部行情请求、全池分钟下载或新的前端定时器。

实现：`candle-history.mjs`、`assets/candle-data.js`、`assets/candle-charts.js`、`assets/candle-loader.js`，由原图表控制器接入。
